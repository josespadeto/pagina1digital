Perguntas Frequentes.

Preciso pagar alguma mensalidade?
Não. O site é seu. A hospedagem em serviços como o GitHub Pages é gratuita. Você só paga pelo domínio (se quiser um personalizado, como .com.br), que custa cerca de R$ 40/ano.
Vou conseguir editar o site sozinho depois?
Sim. Posso entregar o site com uma estrutura simples, ou posso fazer pequenos ajustes para você. Como o site é estático, ele não precisa de manutenção constante, apenas atualizações pontuais quando você quiser.
O site vai aparecer no Google?
Sim. O código é construído com as melhores práticas de SEO técnico: velocidade, meta tags, estrutura semântica e Open Graph. Isso facilita a indexação pelo Google e ajuda o seu negócio a ser encontrado.
